# 経済データ分析Ⅱ

## 教材

- [第2回 住宅の広さと人口密度](https://toyabet.github.io/econ_data_analysis_2/lab/index.html?path=session2.ipynb)

## Notebookの使い方

1. 左側のファイル一覧から、授業で指定されたNotebookを開きます。
2. カーネルを選ぶ画面が表示されたら、`Python (Pyodide)` を選びます。
3. コードセルを選び、`Shift + Enter` で実行します。初回の起動とライブラリの読み込みには時間がかかることがあります。

## 保存とダウンロード

編集内容は、使っているブラウザに保存されます。別のパソコンやブラウザには自動で引き継がれません。ブラウザのデータを消すと、保存内容も失われることがあります。

実習を終えるときは、Notebookを保存してから、左側のファイル一覧で対象のファイルを右クリックし、「ダウンロード」を選び、`.ipynb` ファイルを手元に残してください。別のパソコンで続けるときは、そのファイルをアップロードします。
