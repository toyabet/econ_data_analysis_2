## 教材の追加

公開するNotebookと必要なデータを `content/` に置き、`main` に反映すると、GitHub Actionsがサイトを更新します。

Notebookのカーネルは `Python (Pyodide)` を指定します。科目別の保存領域と日本語の表示設定は `jupyter-lite.json`、`overrides.json` で管理します。
